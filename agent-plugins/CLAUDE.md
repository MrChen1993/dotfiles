# 说明
这是一个CLAUDE 的plugin项目.目的是当给出一个A股上市公司或经济方便的命题，通过多方的辩论角色扮演模拟

# 插件内容

## agent
- 量化专家
- 散户
- 机构

这些agent能使用所有公开技能，假设没有内幕交易，仅从不同的心理对同一件事儿进行多方看法，这些agent要像人一样交流，表达自然

## skill
- 通过网络获取基本面的财报数据、分红数据、实时股票
- 通过网络搜索获取相关行业信息、同业对比
- 通过网络搜索获取公司的经营业务内容，进行经营层面的分析，例如门槛等
- 结合历史数据进行对比
- 结合国际实事、国家政策等

## mcp
按照https://pypi.org/project/akshare-mcp/安装。使用uv进行python包安装运行

## command
调用此command时，你会根据给出的观点，按照如下流程进行：
- 生成一个team,启动两个量化专家的队员进行多空辩论或正反方辩论，辩论时注意必须要正面去回应前一个agent给出的观点.
- 直到双方中有一方被说服
- 汇总对话内容
- 同时启动一个机构和一个散户的子agent，分别带入自己的心理，给出自己的投资想法和理由
