# RESOURCES.md 格式

`RESOURCES.md` 是本主题精选的可信来源集。讲解用的知识应取自这里，而不是凭脑补。智慧来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识（Knowledge）

- [书：《Effective Java（第三版）》— Joshua Bloch](https://example.com)
  Java 最佳实践经典。用于：泛型、枚举、并发、对象设计等惯用法。
- [文章：「Java Stream 详解」— 某权威博客](https://example.com)
  对 Collector / 并行流的深入讲解。用于：Stream 进阶用法。

## 智慧（社区）

- [Stack Overflow — java 标签](https://stackoverflow.com/questions/tagged/java)
  高信号问答社区。用于：具体报错排查、API 用法确认。
- 线下：{某技术沙龙 / 团队内部分享}
  用于：在真实评审里检验设计判断。
```

## 规则

- **只收高可信。** 优先一手来源、公认专家、同行评审、强治理的社区。营销冒充教育的，剔除。
- **每条都加注解。** 三个月后一条裸链接毫无用处。加一行：它讲什么、什么时候该找它。
- **按「知识 / 智慧」分组。** 对应 [SKILL.md](./SKILL.md) 里的理念。一个资源只出现在一组里也没关系。
- **明确标出缺口。** 如果 mission 需要的某个领域没有好资源，写一个 `## 缺口` 小节列出缺什么。这驱动后续搜索。
- **狠心精简。** 被证明错误、肤浅或跑题的资源要删掉，而不是埋着。五个锋利的来源胜过三十个平庸的。
- **记录社区偏好。** 如果用户选择不加入社区，在这里注明，免得后续反复推荐。
