# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的规范用语。所有讲解、练习、学习记录都要遵循它的术语。建术语表本身就是学习的一部分：能把一个概念压缩成一句紧凑的定义，就是用户理解了它的证据。

## 结构

```md
# {主题} 术语表

{一两句话描述这份术语表覆盖的主题。}

## 术语

**幂等（Idempotent）**：
同一个操作执行一次和执行多次，对系统状态的影响相同。
_避免说成_：重复无害、可重试

**背压（Backpressure）**：
下游消费速度跟不上时，反向限制上游生产速度的机制。
_避免说成_：限流、削峰
```

## 规则

- **只在用户理解后才加一个术语。** 术语表是「已压缩知识」的记录，不是给用户读着学的词典。用户刚被引入一个概念时，等他能正确使用了再收进来。
- **要有主见。** 同一概念有多个叫法时，挑最好的一个，其余列为「避免说成」。语言就是这样压缩的。
- **定义要紧。** 一两句话。定义这个术语「是什么」，不是「做什么」或「怎么做」。
- **定义里也用术语表自己的词。** 一个术语进了表，就到处优先用它——包括在别的定义内部。这能让复杂术语日后更好懂。
- **自然成簇时用子标题分组**（如 `## 并发`、`## 存储`）。术语内聚时，扁平列表也行。
- **明确标出歧义。** 如果一个词在更大的领域里用得很松，注明本工作区的取定：「本工作区里『消息』一律指已确认投递的消息，未确认的另算。」
- **随理解加深而修订。** 用户第一周写的定义，第六周可能就错了。原地更新，别留陈旧条目。
